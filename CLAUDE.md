# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this repo is

A fork of "Awesome ChatGPT Prompts": a content repository with no application code and no build step. The prompt collection exists in two places that must stay in sync:

- `README.md`: one `## Act as …` section per prompt (starting after "Other Prompting Resources"), rendered as a GitHub Pages / Jekyll site (`_config.yml`, `_layouts/default.html`, custom domain in `CNAME`).
- `prompts.csv`: the same prompts as `"act","prompt"` rows. This is the machine-readable source (consumed by `scripts/find-prompt` and the upstream Hugging Face dataset).

`AIWorkspace/01 Rezeptfinder/` holds the fork-specific "Rezeptfinder" project in German: standalone recipe pages (`tomaten-gnocchi-pfanne.html`, `rezeptfinder.html`) and a reworked recipe prompt (`sternekoch-prompt.md`). The folder name contains a space, so quote paths in shell commands. Jekyll copies the HTML files unchanged because they have no front matter.

## Adding or editing a prompt

Per `CONTRIBUTING.md` and `.github/pull_request_template.md`:

- Add the prompt to **both** `README.md` and `prompts.csv`.
- README format: `## Prompt Title`, then `Contributed by: [@user](https://github.com/user)`, then `> prompt text`. If ChatGPT generated the prompt, append `<mark>Generated by ChatGPT</mark>` to the contributor line.
- CSV rules:
  - Put the title in the `act` column without the leading "Act as".
  - Quote every field and escape inner quotes by doubling them (`"Hello","Say ""Hi"""`).
  - Leave no space after the comma between fields.
  - Leave no trailing whitespace on any line.

## Checks (mirror CI)

CI (`.github/workflows/csv_linter.yml`) runs on every push/PR and only validates the CSV:

```bash
pip install csvkit
find . -name "*.csv" -exec csvclean -n -u 2 {} +   # must print "No errors."
grep -n "[[:space:]]$" prompts.csv                  # must print nothing
```

## Recipe pages (`AIWorkspace/01 Rezeptfinder/`)

- The HTML files were written as claude.ai Artifacts. They have no `<html>/<head>/<body>` tags because the Artifact publisher wraps them in a skeleton. Keep that shape when editing and republishing.
- Each page is self-contained: inline CSS/JS, Google Fonts only, no external images. The dish images are drawn on `<canvas>` with a seeded RNG.
- Colors are CSS tokens on `:root` with dark-mode overrides (`prefers-color-scheme` and `[data-theme]`).
- `rezeptfinder.html` uses the Artifact runtime capability `sample` (`await claude.use("sample")`) to ask Claude for suggestions and full recipes as JSON. Without that capability it falls back to the built-in `LIB` recipe array.
- `rezeptfinder.html` also declares the `mcp` capability for the viewer's Notion connector (`notion-search`, `notion-create-pages`, `notion-create-attachment`, `notion-update-page`; any new tool must also be added to the manifest on publish). "Ins Rezepte Buch speichern" first checks for a duplicate title, then creates a page in the owner's "Rezepte Buch" data source (`BOOK_DS`, status "Als nächstes ausprobieren"). It also sets the multi-select property `Kategorie` (same options as `KATS`) from `notionKats()`: the main category plus "Vegetarisch"/"Vegan" for meat- and fish-free dishes. The database has a board view "Nach Kategorie" grouped by that property. The page body is Markdown built by `notionMarkdown()` from the scaled amounts currently shown. It always ends with a `## Quelle` section (original link, or "Von Claude erstellt" plus a Chefkoch comparison search). Allergens are split by `groupAllergens()` into EU-14 allergens (milk products are named "Laktose", or "Milcheiweiß" when no lactose is present; never "Milch") and intolerances (Histamin, Fructose). The recipe's `emoji` becomes the page icon.
- Images in Notion: a page cover only accepts a public `https` image URL (an uploaded file is rejected with "Invalid page cover URL"), so the optional "Foto-Link" field is the only way to set a real cover. Two more ways exist: the "Bild speichern" button (`downloads` capability) saves the plate as a 1600×800 JPG for Notion's Cover → Hochladen; and for covers set from a Claude Code session, render the JPG into `AIWorkspace/01 Rezeptfinder/bilder/<slug>.jpg`, push it, and use the commit-pinned `raw.githubusercontent.com/<owner>/<repo>/<sha>/…` URL (the repo is public) as the cover. `notion-create-attachment` with that `source_url` also gives a file ID for the `Bild` property. Independently, `uploadDishImage()` renders the canvas plate as a vector SVG (`svgPlate()`, a small Canvas-2D-to-SVG recorder that replays `drawPlate()`), uploads it with `notion-create-attachment` (text content, max ~200 KiB), puts `<image source="file-upload://…">` at the top of the page and fills the files property `Bild`. A failed upload never blocks saving. "Bild nachtragen" (and "Bild bei diesem Rezept ergänzen" in the duplicate dialog) backfills the image on an existing page via `notion-update-page`.
- Other "Rezepte Buch" properties filled on create: `Description`, `Personenanzahl`, `Zutaten` (comma list), `userDefined:URL` (original link only). If Notion rejects them with `tool_error` (e.g. a property was removed), the create is retried once with only Name/Status/Kategorie.
- "Meine Rezepte": every recipe the viewer opens is added by `addToBook()` and listed at the bottom, grouped by `KATS` (Vorspeisen, Pasta, Fleisch, Fisch, Vegetarisch, Vegan, Dessert, Backen/Kuchen). The category comes from Claude's `kategorie` field, else `guessKat()` keyword rules; a course word in the name (Suppe → Vorspeisen, Kuchen → Backen/Kuchen) wins over a bare diet category from Claude. Storage is the `db` capability in the viewer's private `data/users/<id>` collection (needs `user`), mirrored to `localStorage` as a fallback.
- The platform-search links and the "Rezept von einer Plattform übernehmen" import form were removed on request. Imported recipes saved earlier still render (`importiert` flag in `sourceInfo()`).
- Recipe data uses one schema across the built-in `LIB` and Claude's output: `zutaten[{menge, einheit, name, name_plural, hinweis, allergene[]}]`, `schritte`, `naehrwerte`, `hinweise`, `farben`. Ingredient amounts are scaled by `amount()`. Allergen codes such as `gluten`, `laktose`, `milcheiweiss`, `ei` and `nuesse` are shared between the form chips, the prompt and the conflict check.
- Quick smoke test: the pages render as plain local files in Playwright/Chromium (`file://…/AIWorkspace/01 Rezeptfinder/<page>.html`). To exercise `rezeptfinder.html` without Claude, stub `window.claude.use` (`sample`, `mcp`, `db`, `user`) before the page loads.
